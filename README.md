# TryHackMe Writeups and Lab Work

Notes, writeups and original lab exercises from my work through TryHackMe's Jr Penetration Tester path. Everything here is my own documentation, not a copy of room content.

## Scope and ethics

All testing happens in isolated TryHackMe lab environments or my own self-hosted lab, host-only networking, no bridged exposure, no real targets. No flags, credentials or room-specific exploit code are published here. Writeups describe process and reasoning, not step-by-step solutions.
